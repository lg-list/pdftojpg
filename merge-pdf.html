When to merge PDFs

Merge PDF is useful when invoices, forms, contracts, scanned pages, or report sections need to travel together as one file. Combining documents reduces attachment clutter and helps the recipient read pages in the intended order.

Before downloading the merged file

Check that the selected PDFs are in the right order before merging. The files are processed in the browser, which is helpful for documents that should not be sent to a third-party upload service.
